# 知序 · 计算机成长空间

这是围绕「技术成长 + 求职面试 + 考研升学」制作的第一版可交互网站原型。

## 启动

需要 Node.js 20 或更新版本。网站本身不依赖第三方运行时库。

```powershell
cd C:\Users\陈乐天\code\computer-learning
npm start
```

打开 http://127.0.0.1:4173 。可使用环境变量 PORT 更改端口。服务仅监听本机。

## 这一版可以实际体验

- 20 条技术路线、100 个阶段任务：Agent、机器学习、深度学习、大模型预训练/后训练、前端、后端、软件开发、测试、运维、算法、计算机基础、产品经理和数据分析。
- 145 个学习资源入口，其中 94 份为中文入口：每个方向关联 9–21 份资料，且至少包含 5 份中文资料。支持方向、语言、学习阶段组合筛选、中文快捷筛选与收藏，附练习产出建议。
- 搜索技术路线、资料、考研专题、公司和笔试面试练习。
- 求职面试：20 个岗位方向 × 字节跳动、阿里巴巴、腾讯、月之暗面、MiniMax 五家公司，支持可分享的筛选链接。
- 56 道站内原创练习：笔试、专业面试、项目深挖，含答题要点、失分提醒与复盘标记。
- 5 份有来源的公开面经摘要和原文链接；所有岗位/公司组合都有公开面经检索入口。
- 按岗位与公司分别保存个人面试复盘，支持导出与清空；另含六类准备技巧。
- 加入学习、标记阶段、查看进度、暂停及恢复路线。
- 考研 408 四门专业课的原创复习提纲。
- 根据周数、每日时间、专业课类型生成并导出初始复习草案。
- 择校、复习规划、答疑、复试四类帮扶需求草稿：保存、删除和导出。
- 手机和平板布局、移动导航、键盘操作与弹窗。

## 数据和服务边界

- 用户记录保存在浏览器 localStorage，尚无注册、登录、数据库或跨设备同步。
- 帮扶需求是本地草稿，不会发送给导师；没有真实预约、排期、支付或在线咨询。
- 资料库是外部资源导航，不是本站托管的完整课程、题库或教材。
- 408 提纲是学习组织示例，不代替报考年份的考试大纲和院校通知。
- 复习草案采用固定比例，是可调整的起点，不是基于诊断的个性化推荐。
- 面经摘要来自公开用户自述，本站无法独立验证实际面试过程；历史样本不代表当前招聘流程。原创练习和公司场景为编辑建议。
- 外部网站内容、可访问性和课程条件可能变化，发布前需要做人工资源审核。

## 文件

- `index.html`：页面框架。
- `style.css`：响应式页面样式。
- `app.js`：页面、交互与本地记录。
- `data.js`：技术路线、资源、考研提纲和帮扶项目。
- `career-data.js`：公司、岗位准备、练习和公开面经来源。
- `career-ui.js`：公司岗位筛选、练习进度、面经与个人复盘。
- `SOURCES.md`：公司招聘、面经和新增中文资料来源及核验结果。
- `core.js`：搜索、进度、数据校验与复习计划计算。
- `server.mjs`：本地静态文件服务，仅提供明确允许的前端文件。
- `PRODUCT.md`：网站结构、后续正式服务与内容建设方案。
- `tests/`：核心逻辑与浏览器验证。
- `artifacts/`：桌面与手机端检查截图。

## 动态交互主页（2026-10-19）

- 原生 Canvas 绘制缓慢旋转的知识网络、节点连线与流动光点；叠加芯片扫描、核心呼吸、标题渐变与终端逐字输入。
- 精细指针设备支持局部光照和芯片视差；学习卡片加入悬停反馈与进入视口时的渐显。
- 首页提供「暂停动效 / 开启动效」按钮，支持键盘与触屏，选择保存在本地；系统启用减少动态效果时自动使用静态展示。
- Canvas 绘制上限为每秒 24 帧，像素比上限为 1.5，手机端将网络节点从 64 个减少到 36 个；主页离开视口、标签页隐藏时停止持续渲染，切换页面时释放监听器和观察器。
- 兼容明暗主题和 320–1920px 布局，无新增外部资源或运行时依赖。
- `npm run test:motion` 检查实时绘制、终端更新、指针视差、键盘/触屏暂停、偏好记忆、视口外暂停、减少动态效果、路由清理、双主题响应式布局及绘制频率上限。
