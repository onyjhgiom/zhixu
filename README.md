# 知序 · 计算机成长空间

这是围绕「技术成长 + 项目实践 + 求职面试 + 考研升学」制作的第一版可交互网站原型。

## B站学习入口（2026-10-23）

技术路线、考研专题、专业方向与岗位卡片，以及路线阶段、理论/实操模块和技能树提供独立的 B站学习入口。项目实践按当前方向同步课程；面试、复盘、准备方法、简历和考研帮扶使用相应的视频。资料库新增可展开的 B站课程目录，并跟随方向筛选。外链在新标签页打开，不传递草稿、姓名、联系方式或照片，不改变现有进度和表单。

维护资源请修改 `video-data.js` 中的课程和稳定 ID 映射；展示逻辑位于 `video-ui.js`，主题样式位于 `video.css`。添加新方向/阶段后运行 `npm test` 和 `npm run test:videos` 检查覆盖与交互；`npm run check:videos` 联网检查全部 BV号的公开元数据，不能替代实际播放检查。来源和旧版课程限制见 `SOURCES.md`。静态部署包含这三个文件；修改服务器公开文件列表后需重启 Node 服务。

## 智能简历生成（2026-10-22）

求职面试页的「智能简历生成」入口与第四个内容标签进入 `#interviews?tab=resume`，保留当前岗位与公司上下文。

- 五步填写：基本信息与证件照、教育背景、工作 / 实习与项目、技能证书与目标 JD / HC、生成预览。经历可添加、移除，表单自动保存在独立的 `zhixu-resume-v1` 草稿中。
- 证件照支持 JPG / PNG / WebP（不超过 5MB），在浏览器内裁切为 4:5 并压缩，支持更换与移除；不上传服务器。
- 基于用户粘贴的 JD 与 HC 描述提取技能关键词、识别别名，按职责与必备程度加权；优先展示相关模块、经历与要点，高亮已有证据支持的关键词，区分已覆盖与待补充要求。不开启优化时保留表单顺序。
- 预览中可直接编辑姓名、联系方式、模块标题和经历文字，刷新后保留；表单修改会提示预览待更新。重新生成前可选择保留在线编辑，避免意外覆盖。
- 下载 A4 PDF 或 2 倍分辨率 PNG，长简历自动分页，多页 PNG 打包为 ZIP 一次下载。中文、照片与在线编辑内容均进入导出；PDF 使用页面图像，暂不提供可搜索的文本层。

生成预览默认使用本地排版。用户开启 AI 后，服务端通过 OpenAI 兼容的 Chat Completions 协议调用 GPT，默认模型为 `gpt-6-astra`；模型列表按服务商实际返回展示。列表只说明服务商声明的模型 ID，不代表上游账号当前可用。生成失败时页面显示对应说明并保留原预览，仍可选择本地排版。

AI 请求只包含经历、技能、简介与岗位文本，独立的姓名、联系方式、所在城市、主页和照片字段不发送给接口。已有经历仍可能包含个人信息，按填写内容处理。姓名、联系方式、照片和生成草稿由本地表单合并；服务器不持久保存请求或响应。AI 结果按原始经历下标关联，保留学校、单位、职位、时间和证书，对新增技能关键词、数字变化、遗漏经历与无效结构做校验；校验不能替代本人对表达真实性的复核。匹配覆盖度仍按本地表单证据计算，不代表录用概率。原有题库、复盘、学习与成长记录使用原存储键。

服务端自动读取项目根目录的 `.env.local`，已加入 Git 忽略列表且不对浏览器公开。当前 GPT 配置使用 `RESUME_AI_PROTOCOL=chat-completions`、`SUB2API_BASE_URL`、`SUB2API_API_KEY` 和 `OPENAI_MODEL=gpt-6-astra`，以 Bearer 认证请求 `/v1/chat/completions`，并传入 `store: false`。仍兼容 Sub2API Responses 与 Anthropic Messages 协议；切换协议时需同步设置对应的服务端环境变量。密钥仅用于服务端认证；修改配置后重启 Node 服务。

2026-10-24 联调：附带密钥的 `/v1/models` 成功返回 GPT 模型列表；以 `gpt-6-astra` 对无个人信息的测试简历完成了真实生成与结果校验。

`resume-core.js` 提供状态清洗、表单校验、关键词分析与文档生成，`resume-ai-core.js` 提供请求脱敏和响应校验，`resume-ai.mjs` 负责服务端模型列表与生成调用，`resume-ui.js` / `resume.css` 提供页面与编辑，`resume-export.js` 负责浏览器排版、分页与导出。PDF 依赖本地安装的 jsPDF，按需通过静态服务的明确白名单路径加载，无外部 CDN 请求。

验证：`npm test` 包含简历状态恢复、JD / HC 权重、技能别名、AI 请求脱敏、结果校验、模型路由、服务端错误与接口边界；`npm run test:resume` 用模拟 AI 响应验证完整填写、模型切换、生成与取消、失败保留草稿、本地回退、照片、在线编辑与恢复、PDF / PNG 下载、多页 PDF、双主题响应式、存储异常降级及原面试记录隔离，运行时不消耗真实模型额度。浏览器测试可通过 `TEST_BASE_URL` 指定运行中的服务，真实服务联调结果见上文。

## 数据和服务边界

- 用户记录保存在浏览器 localStorage，尚无注册、登录、数据库或跨设备同步。
- 帮扶需求是本地草稿，不会发送给导师；没有真实预约、排期、支付或在线咨询。
- 资料库是外部资源导航，不是本站托管的完整课程、题库或教材。
- 408 提纲是学习组织示例，不代替报考年份的考试大纲和院校通知。
- 复习草案采用固定比例，是可调整的起点，不是基于诊断的个性化推荐。
- 面经摘要来自公开用户自述，本站无法独立验证实际面试过程；历史样本不代表当前招聘流程。原创练习和公司场景为编辑建议。
- 外部网站内容、可访问性和课程条件可能变化，发布前需要做人工资源审核。

## 项目实践板块（2026-10-19）

沿用原生 HTML、CSS、JavaScript ES Modules 与 hash 路由，无新增运行时依赖。入口是侧栏「项目实践」、首页实践提示，以及每条技术路线弹窗内的岗位实践链接。

- 输入与筛选仅更新卡片的显示状态、结果数及 URL，不重新创建页面和卡片，不重启动效；支持中文输入法合成、焦点保持、无结果重置及分享后刷新还原。筛选修改使用 replaceState，返回键直接回到上一页面。
- 卡片为原生链接，可整卡点击、键盘 Enter 打开或使用浏览器右键菜单。外链统一设置新标签页及 noopener、noreferrer。校验支持 GitHub、Gitee 的 HTTPS 仓库地址；目前 44 条示例均为 GitHub 仓库。
- 地区表示公开发起机构所在地或全球协作属性，不代表线下实习或招聘地点。具体机构资料保存在 location.source，未明确地点的项目统一标记全球协作。
- 复用全站主题变量、卡片与流体视觉；大屏三列、中屏两列、手机单列。系统减少动态效果偏好继续生效。

新增项目请编辑 project-data.js 的 projects 数组：id（唯一标识）、roles（data.js 中已有方向 ID）、title、desc、url、location（region / label / note，可含 source）、level、tags、practice、deliverable。地区选项由 projectRegions 定义；添加地区时同时补充说明及验证。

静态部署时须一并上传 project-data.js 与 project-ui.js。修改 server.mjs 的公开文件列表后，已运行的 Node 服务需要重新启动。
